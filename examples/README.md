# MIS-Teach Exam Transcription synthetic examples

- `demo_question_input.json` documents the intended question domain. The actual pipeline input is a permitted PDF.
- `demo_transcription_output.json` documents a safe output shape.

Neither file is an examination, source PDF, image crop, or generated research output.

No examination PDF, scanned page, cropped image, or generated question JSON is included in
this public package. Use a document that you are permitted to process, place it in the ignored
`input/` directory, and write generated output to the ignored `generated/` directory.

The repository-root `examples/` directory contains synthetic, non-source-data JSON examples for
the broader MIS-Teach system.
